## Как се играе

Пишеш команди в терминала и натискаш **Enter**. Във всяко от шестте нива трябва да намериш парола и да я въведеш с `unlock <парола>`. Командата `help` показва какво можеш, `man <команда>` обяснява подробно всеки инструмент, а `hint` дава подсказка срещу 75 точки.

| Ниво | Сървър | Какво учиш |
|---|---|---|
| 1 | helios-guest | `ls`, `cd`, `cat`: навигация във файлова система |
| 2 | helios-portal | скрити файлове (`ls -a`), `.bash_history` |
| 3 | helios-mail | шифър на Цезар |
| 4 | helios-db | Base64 (и защо това не е шифроване) |
| 5 | helios-logs | `grep` и пайпове (`cat auth.log \| grep root`) |
| 6 | helios-core | шестнадесетичен и двоичен код, обърнат текст |

Удобства:

- **Tab** допълва имена на команди, файлове и папки (`cat to` + Tab → `cat todo.txt`).
- **↑ / ↓** връщат предишни команди.
- **Пайп `|`** подава изхода на една команда към друга: `cat auth.log | grep root`.
- Прогресът се пази автоматично в браузъра. Може да затвориш таба и да продължиш по-късно.
- Всеки клавиш или клик прескача анимациите с текст.
- На телефон има бутони за най-честите команди под терминала.

## Команди

| Команда | Какво прави |
|---|---|
| `ls [-a] [папка]` | показва файловете; `-a` показва и **скритите** (имената им започват с точка) |
| `cd <папка>` | влиза в папка; `cd ..` е нагоре, `cd ~` е вкъщи |
| `cat <файл>` | показва съдържанието на файл |
| `pwd` | показва къде си |
| `tree [-a]` | рисува дървото от папки (шумно: +5% следа) |
| `find <име>` | търси файл по име из целия сървър (много шумно: +8% следа) |
| `echo <текст>` | отпечатва текст, удобно с пайп |
| `unlock <парола>` | въвежда намерена парола |
| `note [текст]` | бележник в страничния панел; `note -d <n>` трие, `note -c` чисти |
| `man <команда>` | подробно ръководство, например `man grep` или `man pipe` |
| `hint` | подсказка за нивото (−75 точки, по 3 на ниво) |
| `status` · `achievements` | прогрес · постижения |
| `clear` · `sound` · `reset` | чисти екрана · звук · нова игра |

Инструменти, които се отключват по пътя: `caesar` (ниво 3), `base64` (ниво 4), `grep` (ниво 5), `hex`, `bin`, `rev` (ниво 6).

Има и скрити команди: `sudo`, `kafe`, `neofetch`, `whoami`, `date`, `vim`, `hack`… пробвай ги.

## Точки, следа и рангове

| Събитие | Точки |
|---|---|
| Минато ниво | **+500** |
| Ниво, минато за под 2 минути | **+100** бонус |
| Подсказка (`hint`) | **−75** |
| Засичане (следата стига 100%) | **−150** |

**Следа.** Всяка „истинска“ команда (`ls`, `cd`, `cat`, `grep`…) добавя 3% към лентата „СЛЕДА“, `tree` добавя 5%, `find` 8%, а **грешна парола 12%**. При 100% системата те засича: губиш 150 точки и се връщаш в началната папка. Над 70% екранът пулсира в червено. `help`, `hint`, `note`, `man`, `status` и `clear` не оставят следа. Следата се нулира в началото на всяко ниво.

**Рангове:** Скрипт-хлапе (под 1900) → Хакер (1900+) → Призрак (2600+) → Легенда (3200+). Максимумът е **3600**: 6 нива × (500 + 100), без подсказки и засичания.

<summary><b>Финалът</b> — два края</summary>

| Команда | Край |
|---|---|
| `delete kontrolno` | Изтриваш само проекта. ХЕЛИОС оцелява и започва да помага с домашните… учтиво. (**Дипломат**) |

Изборът не влияе на точките. С `reset` започваш наново. Постиженията остават, така че можеш да изиграеш и другия край.

## Постижения

14 постижения, пазят се и след `reset`. За всички трябват поне две игри (двата края).

| Постижение | Как се взима |
|---|---|
| Вътре съм | Мини ниво 1. |
| Чета упътванията | Използвай `man`. |
| Водопроводчик | Свържи две команди с `\|`. |
| Детектив | Запиши бележка с `note`. |
| Археолог | Прочети дневника на ХЕЛИОС в ниво 6. |
| Без патерици | Завърши без нито един `hint`. |
| Невидим | Завърши, без следата да стигне 100%. |
| Светкавица | Мини всяко ниво за под 2 минути. |
| Легенда | Завърши с 3200+ точки. |
| Дипломат | Финал с `delete kontrolno`. |
| Терминатор | Финал с `shutdown helios`. |

## Технически детайли

- Чист HTML, CSS и JavaScript, без библиотеки, без бекенд и без билд стъпка
- Виртуална файлова система с относителни и абсолютни пътища (`..`, `~`, `/`)
- Tab допълване, история на командите (↑ ↓), пайпове между команди
- Паролите се пазят като хешове, така че не се виждат в изходния код
- Звукови ефекти с Web Audio API, генерирани в реално време
- Прогресът и постиженията се пазят в localStorage
- Работи на телефон, с бутони за най-честите команди
- CRT ефекти: включване на екрана, сканиращи линии, червена тревога при висока следа
- Карта на мрежата, бележник и известия за постижения

```
index.html        разметката на страницата
favicon.svg       иконата в таба
css/style.css     всички стилове и анимации
js/levels.js      нивата, файловите системи, man страниците и постиженията
js/sound.js       звуковите ефекти (Web Audio)
js/game.js        двигателят: терминал, команди, точки, запазване
```

Скриптовете са обикновени (не ES модули), за да работи играта и при директно отваряне на `index.html` от диска. Ново ниво се добавя като нов обект в `LEVELS` в `js/levels.js`.
