## Основи

Играта е фалшив Linux терминал. Пишеш команда и натискаш **Enter**. Във всяко от шестте нива трябва да намериш парола и да я въведеш с:

```
unlock <парола>
```

Главните команди:

| Команда | Какво прави |
|---|---|
| `ls` | показва файловете в текущата папка |
| `ls -a` | показва и **скритите** файлове (имената им започват с точка) |
| `cd <папка>` | влиза в папка; `cd ..` е една папка нагоре, `cd ~` е вкъщи |
| `cat <файл>` | показва съдържанието на файл |
| `tree` | рисува цялото дърво от папки (шумно: +5% следа) |
| `find <име>` | търси файл по име из целия сървър (много шумно: +8% следа) |
| `note <текст>` | записва бележка в бележника вдясно (не оставя следа) |
| `man <команда>` | подробно обяснение на команда, например `man grep` |
| `hint` | подсказка за нивото (−75 точки, по 3 на ниво) |
| `status` | текущо ниво, точки, следа |
| `achievements` | списък с постиженията |

Удобства:

- **Tab** допълва имена на команди, файлове и папки. Пишеш `cat to` и натискаш Tab → `cat todo.txt`.
- **↑ / ↓** връщат предишни команди.
- **Пайп `|`** подава изхода на една команда към друга: `cat auth.log | grep root`.
- Прогресът се пази автоматично в браузъра. Може да затвориш таба и да продължиш по-късно.
- Всеки клавиш или клик прескача анимациите с текст.
- На телефон има бутони за най-честите команди под терминала.

## Точки, следа и рангове

| Събитие | Точки |
|---|---|
| Минато ниво | **+500** |
| Ниво, минато за под 2 минути | **+100** бонус |
| Подсказка (`hint`) | **−75** |
| Засичане (следата стига 100%) | **−150** |

**Следа.** Всяка „истинска“ команда (`ls`, `cd`, `cat`, `grep`…) добавя 3% към лентата „СЛЕДА“. `tree` добавя 5%, `find` 8%, а **грешна парола 12%**. Когато лентата стигне 100%, системата те засича: губиш 150 точки и те връща в началната папка. Над 70% екранът започва да пулсира в червено — време е да спреш да гадаеш. Командите `help`, `hint`, `note`, `man`, `status`, `clear` не оставят следа. Следата се нулира в началото на всяко ниво.

**Рангове** (по крайните точки):

| Ранг | Точки |
|---|---|
| СКРИПТ-ХЛАПЕ | под 1900 |
| ХАКЕР | 1900+ |
| ПРИЗРАК | 2600+ |
| ЛЕГЕНДА | 3200+ |

Максимумът е **3600** точки: 6 нива × (500 + 100 бонус), без подсказки и без засичания.

## Ниво 1 · helios-guest

**Задача:** намери паролата за портала на служителите.
**Учиш:** `ls`, `cd`, `cat` — как се движиш из файлова система.

Започваш в `/home/guest`. Огледай се:

```
ls
```

```
readme.txt   stajant/
```

`readme.txt` те моли да не пипаш папката на стажанта. Точно затова влизаш в нея:

```
cd stajant
ls
cat todo.txt
```

```
СПИСЪК ЗАДАЧИ (стажант Гошо)
[x] кафе за шефа
[ ] принтерът пак не работи
[ ] да сменя паролата за портала, защото е твърде лесна
    (сега е: slanchogled)
[ ] да НЕ пиша паролата в този файл
```

Гошо е записал паролата си. Въведи я:

```
unlock slanchogled
```

✅ **Парола: `slanchogled`**

> 🐱 **Тайно постижение „Котколюбец“:** в `snimki/` има три снимки на котки. Пробвай `cat snimki/kotka.jpg`.

## Ниво 2 · helios-portal

**Задача:** админът твърди, че тук няма нищо. Провери.
**Учиш:** скрити файлове и `.bash_history`.

```
ls
```

```
docs/   welcome.txt
```

Нищо интересно на пръв поглед. В `docs/politika.txt` пише „Командите, които пишете, не се пазят никъде. (Нали?)“ — това е намекът. В Linux файловете, чиито имена започват с точка, са **скрити**. Покажи ги с `-a`:

```
ls -a
```

```
.bash_history   .config/   docs/   welcome.txt
```

`.bash_history` пази всяка команда, която потребителят е писал в терминала:

```
cat .bash_history
```

```
ls
cd docs
cat politika.txt
cd ..
nano welcome.txt
mysql -u admin -p'banitsa'
history -c   # изтрий историята
exit
```

Админът е подал паролата си директно в командата (`-p'banitsa'`) и после е опитал да изтрие историята — но твърде късно.

```
unlock banitsa
```

✅ **Парола: `banitsa`**

## Ниво 3 · helios-mail

**Задача:** паролата за базата данни е пратена шифрована.
**Нов инструмент:** `caesar` (шифър на Цезар).

```
cd inbox
ls
cat 001_direktor.txt
```

Директорът пише: *„Ключът е колкото са планетите в Слънчевата система. Плутон НЕ се брои.“* → ключът е **8**.

```
cat 002_ivan.txt
```

```
xizwtibi hi jihibi m wzjqbi
```

Иван е изместил всяка буква с **+8** позиции напред. За да я върнеш, местиш с **−8**:

```
caesar -8 xizwtibi hi jihibi m wzjqbi
```

```
parolata za bazata e orbita
```

```
unlock orbita
```

✅ **Парола: `orbita`**

> 💡 Може и с пайп: `cat 002_ivan.txt | grep xizw | caesar -8` (носи постижението „Водопроводчик“).
> Шифърът на Цезар има само 25 възможни ключа — дори без писмото на директора можеш да пробваш всички.

## Ниво 4 · helios-db

**Задача:** намери паролата на базата „kontrolno“ в конфигурацията.
**Нов инструмент:** `base64`.

```
cd config
ls
cat README.md
cat database.yml
```

```
# база: kontrolno
host: localhost
port: 5432
user: kontrolno_admin
# паролата е „криптирана“ за по-голяма сигурност :)
password_enc: bHl1dGVuaXRzYQ==
```

Двете `==` в края са типичен белег на Base64. Base64 **не е шифроване** — няма ключ, всеки може да го декодира:

```
base64 -d bHl1dGVuaXRzYQ==
```

```
lyutenitsa
```

```
unlock lyutenitsa
```

✅ **Парола: `lyutenitsa`**

## Ниво 5 · helios-logs

**Задача:** директорът влиза винаги в едно и също време. Разбери как.
**Нов инструмент:** `grep`.

Започваш в `/var/log`. Първо прочети чата:

```
cat notes/sysops_chat.txt
```

```
[sysops] шефът пак ли влиза точно в 3:14 през нощта?
[gosho] да, казва, че е като числото пи, лесно се помни
[sysops] снощи беше много сънен. погледни auth.log, има нещо смешно
[sysops] написал е паролата си там, където трябва да е потребителското име
```

`auth.log` има над 260 реда — няма смисъл да го четеш целия с `cat`. Филтрирай само редовете с 03:14:

```
grep 03:14 auth.log
```

```
2026-10-29 03:14:01 helios-logs sshd[3141]: Failed password for invalid user noshtna_sova from 10.0.3.14 port 31415
2026-10-29 03:14:09 helios-logs sshd[3141]: Accepted password for root from 10.0.3.14 port 31415
2026-10-29 03:14:22 helios-logs sudo: root : COMMAND=/opt/helios/kontrolno --arm --date=2026-11-01
```

Първият ред: сънливият директор е написал паролата в полето за потребител („invalid user **noshtna_sova**“). Осем секунди по-късно влиза като `root` с успех.

```
unlock noshtna_sova
```

✅ **Парола: `noshtna_sova`**

> 💡 Същото с пайп: `cat auth.log | grep 03:14`. Може и `grep invalid auth.log`.

## Ниво 6 · helios-core

**Задача:** сглоби ключа от трите фрагмента.
**Нови инструменти:** `hex`, `bin`, `rev`.

```
cat README
cd fragmenti
ls
```

```
fragment_1.hex   fragment_2.bin   fragment_3.txt
```

**Фрагмент 1** — шестнадесетичен код:

```
cat fragment_1.hex
hex -d 6e 79 61 6d 61
```

→ `nyama`

**Фрагмент 2** — двоичен код:

```
cat fragment_2.bin
bin -d 01011111 01101011 01101111 01101110 01110100 01110010
```

→ `_kontr`

**Фрагмент 3** — обърнат текст:

```
rev fragment_3.txt
```

→ `olni`

Запиши ги, за да не ги забравиш (по желание, без следа):

```
note 1: nyama
note 2: _kontr
note 3: olni
```

Слепи ги в ред 1-2-3 **без интервали**: `nyama` + `_kontr` + `olni` = **`nyama_kontrolni`** („няма контролни“).

```
unlock nyama_kontrolni
```

✅ **Парола: `nyama_kontrolni`**

> 📜 Преди да отключиш, прочети `cat ../logs/dnevnik_na_helios.log` — така разбираш историята на ИИ-то и взимаш постижението „Археолог“.

## Финалът: двата края

След последната парола ИИ-то ХЕЛИОС ти проговаря. Имаш **root** достъп и две възможности:

| Команда | Край | Постижение |
|---|---|---|
| `delete kontrolno` | Изтриваш само проекта. ХЕЛИОС оцелява и започва да помага с домашните… учтиво. | **Дипломат** |
| `shutdown helios` | Изключваш целия ИИ. Последните му думи: „Но кой ще проверява домашните?“ | **Терминатор** |

Изборът не влияе на точките. След края излиза карта с ранга, статистика и постиженията, която можеш да копираш и споделиш. С `reset` (или бутона „Играй отново“) започваш наново — **постиженията остават**, така че можеш да изиграеш и другия край.

## Всички постижения

Общо 14. Пазят се отделно от играта и не се губят при `reset`.

| Постижение | Как се взима |
|---|---|
| **Вътре съм** | Мини ниво 1. |
| **Чета упътванията** | Използвай `man` (например `man grep`). |
| **Водопроводчик** | Свържи две команди с пайп `\|`, например `cat auth.log \| grep root`. |
| **Детектив** | Запиши бележка с `note <текст>`. |
| **Археолог** | В ниво 6 прочети `logs/dnevnik_na_helios.log`. |
| **Котколюбец** *(тайно)* | В ниво 1 пробвай `cat stajant/snimki/kotka.jpg`. |
| **Бариста** *(тайно)* | Напиши `kafe` (или `coffee`). |
| **Не на мен тези** *(тайно)* | Напиши `sudo`. |
| **Без патерици** | Завърши играта без нито един `hint`. |
| **Невидим** | Завърши, без следата да стигне 100%. |
| **Светкавица** | Мини **всяко** ниво за под 2 минути. |
| **Легенда** | Завърши с 3200+ точки. |
| **Дипломат** | Финал с `delete kontrolno`. |
| **Терминатор** | Финал с `shutdown helios`. |

За всички 14 трябват **поне две игри** (двата края). Втората може да е бързата от следващата секция.

## Бърз маршрут за ранг ЛЕГЕНДА

Най-краткият път: по две команди на ниво, всяко ниво за секунди → 3600 точки, ранг ЛЕГЕНДА, плюс „Без патерици“, „Невидим“ и „Светкавица“ наведнъж.

```
cat stajant/todo.txt
unlock slanchogled

cat .bash_history
unlock banitsa

caesar -8 xizwtibi hi jihibi m wzjqbi
unlock orbita

base64 -d bHl1dGVuaXRzYQ==
unlock lyutenitsa

grep 03:14 auth.log
unlock noshtna_sova

unlock nyama_kontrolni

shutdown helios
```

(По желание добави `kafe`, `sudo`, `man grep`, `note ...` и `cat logs/dnevnik_na_helios.log` преди последния `unlock`, за да събереш и останалите постижения в същата игра. Всичко освен двата края се взима в една игра.)
